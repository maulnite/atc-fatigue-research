# Model lokal

Model baseline tersedia lokal pada run directory MRL, DROZY KSS, dan RAVDESS jika run-nya telah selesai. Metadata config/schema dan split/fold manifest berada bersama model atau di `reports/metrics/` untuk run yang sama.

Artefak model diabaikan Git. Catat lokasi dan checksum di laporan run bila sesuai izin; jangan memuat model pickle/joblib dari sumber yang tidak dipercaya.
